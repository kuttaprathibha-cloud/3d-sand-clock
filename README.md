🌞 3D Sundial – Actual Clock

📌 Project Description

The 3D Sundial – Actual Clock is a web-based project that demonstrates a three-dimensional sundial clock. It represents the concept of traditional time measurement using sunlight and shadows in a modern 3D digital environment.

The project provides an interactive visual experience where users can observe a 3D sundial and understand how shadows indicate time.

🎯 Objectives

- To develop a 3D model of a traditional sundial.
- To demonstrate how sunlight and shadows help measure time.
- To create an interactive and user-friendly clock.
- To combine traditional timekeeping concepts with modern web technology.

✨ Features

- 3D sundial visualization.
- Interactive clock interface.
- Real-time clock display.
- Sunlight and shadow representation.
- User-friendly design.
- Responsive interface.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Three.js (for 3D visualization)

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Open "index.html".
5. Click Go Live to run the project in your browser.
